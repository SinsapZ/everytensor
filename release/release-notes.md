EveryTensor 的首个 Windows 早期预览版。用文件名或自然语言描述，搜索本机文档、代码、图片、视频和音频，并在预览中定位相关内容。

## 安装

1. 下载并解压 `everytensor-0.1.0-alpha.1-source.zip`。
2. 安装 64 位 Python 3.11，并将 Python 加入 PATH。
3. 运行 `setup-quick-model.cmd`，安装桌面依赖和轻量文字模型。
4. 安装完成后运行 `launch.cmd`，在设置中确认搜索范围。

如需完整多模态检索，关闭应用后运行 `setup-model.cmd`。视频和音频功能还需另行安装 FFmpeg，并将 `ffmpeg`、`ffprobe`、`ffplay` 加入 PATH。

首次启动默认搜索本机可访问的固定磁盘，建议先在设置中选择较小的资料目录。默认索引预算为 8 GiB，模型空间另计。

## 本版内容

- 文件名、路径、正文关键词和本地语义搜索。
- 文档与媒体预览，以及页码、行号和媒体时间位置。
- 增量索引、暂停与恢复、搜索范围和排除目录设置。
- 修复首页三个示例入口切换时的 hover 高亮重叠。
- 补齐模型安装脚本的环境创建和完整模型下载步骤。

## 当前状态

这是预发布版本，提供源码运行方式，不包含独立安装器、模型权重、运行环境或个人索引。安装依赖和模型需要网络；搜索和模型推理在本机执行。

UI、检索质量和资源占用仍在迭代。已对 100%、125%、150% 缩放下的首页 hover 和点击进行离屏检查；尚未完成全新 Windows 环境的完整安装验收。更详细的要求和限制见仓库 README。
